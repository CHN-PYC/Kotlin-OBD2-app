# 余弦相似度（离线学习）

## 目的、输入和输出

比较两个向量的方向，为后续 Top-K 排序提供分数。
输入：两个等长的非空、有限数值、非零向量；输出：[-1, 1] 范围内的浮点数。
本节用人工构造向量讲解数学，不联网、不下载模型、不安装依赖。
没有真实语义向量，不代表已经评测车辆知识检索效果。

## 算法与选择理由

```text
cosine(a, b) = dot(a, b) / (length(a) * length(b))

先检查维度一致
→ 各自变成长度为 1 的单位向量
→ 对应分量相乘再求和
→ 消除浮点舍入造成的轻微越界
```

归一化后内积等于余弦相似度，为后续理解 FAISS IndexFlatIP 做准备。
余弦只比较方向，不会因为给一个向量乘上正数而改变分数。
每次比较按维度数线性计算，当前实现会创建单位向量列表。
小规模学习用标准库 math 即可；真实批量检索后续使用向量化计算或 FAISS，
可以预先归一化知识库，避免每次查询重复处理相同向量。

## 例子

查询 q = [1, 0, 0]：

| 候选向量 | 分数 | 几何意义 |
|---|---:|---|
| [2, 0, 0] | 1 | 同方向 |
| [3, 4, 0] | 0.6 | 部分同向 |
| [0, 1, 0] | 0 | 垂直 |
| [-1, 0, 0] | -1 | 反方向 |

例如 [3,4,0] 长度为 5，单位向量为 [0.6,0.8,0]，与 q 的内积是 0.6。
这是几何例子，不代表文本向量的某一维具有可人为指定的业务含义。
相似度不是概率；0.8 不能解释成“答案有 80% 的概率正确”。

## 边界与数值稳定性

零向量无法定义余弦，拒绝；某几个分量等于零并没有问题。
拒绝 NaN、Infinity、空向量及维度不一致，不用 zip 默认截断掩盖错误。
_unit_vector 先除以最大绝对值，再计算长度，避免极大数值的平方溢出。
两次缩放都不改变方向，可以先理解普通归一化，再回来看这个保护步骤。
math.fsum 改善累加精度；最后限制到 [-1,1] 只用于修正舍入误差，不替代输入校验。

## 验证与调试

测试覆盖同向、垂直、反向、已知分数、缩放不变、对称性、输入不变、
非法向量以及极大/极小有限数值。浮点结果用 pytest.approx 比较。
调试先看向量维度、是否非零，然后看单位向量及分量乘积。
